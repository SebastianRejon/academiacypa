Desarrollo Web

Curso Front End

Aprende los tres lenguajes que conforman el frontend web: HTML, CSS y JavaScript. A lo largo del curso aprenderas a desarrollar webs para empresas y Web Apps de proposito general.

Temario del Curso

  • Módulo 1: Introducción al Desarrollo Web

    Panorama general de cómo funciona la web. Conceptos básicos de cliente-servidor, navegadores, y herramientas necesarias para comenzar a desarrollar.

  • Módulo 2: Fundamentos de HTML

    Estructura básica de una página web. Uso de etiquetas, jerarquía de contenidos, enlaces, imágenes y buenas prácticas semánticas.

  • Módulo 3: Estructuración Semántica

    Uso de etiquetas semánticas para mejorar la accesibilidad y organización del contenido. Introducción a buenas prácticas de maquetado.

  • Módulo 4: Introducción a CSS

    Estilos básicos para páginas web. Selectores, propiedades principales, colores, tipografías y modelo de caja.

  • Módulo 5: Diseño y Layouts con CSS

    Técnicas de diseño moderno como Flexbox y Grid. Creación de layouts responsivos y adaptación a distintos dispositivos.

  • Módulo 6: Fundamentos de JavaScript

    Introducción a la programación con JavaScript. Variables, tipos de datos, estructuras de control y funciones.

  • Módulo 7: Manipulación del DOM

    Interacción con elementos HTML mediante JavaScript. Eventos, cambios dinámicos en la interfaz y manejo básico del DOM.

  • Módulo 8: Proyecto Integrador

    Desarrollo de un proyecto final que combine HTML, CSS y JavaScript, aplicando todos los conocimientos adquiridos en el curso.

Modalidad

Certificado

Certificado de finalización al entregar y aprobar el Proyecto Final.
