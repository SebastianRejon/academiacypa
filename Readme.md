# 📘 Academia CYPA - Sitio Web

Este repositorio contiene el desarrollo del sitio web de **Academia CYPA**, una pagina de aterrizaje y de comunicación sobre mi proyecto de enseñanza.

---

## 🧩 Estructura general del sitio

El sitio está organizado en secciones claras, pensadas para comunicar la propuesta académica y facilitar la navegación del usuario.

### 🏠 Home

Sección principal de bienvenida. Presenta una visión general de la academia, propuesta de valor y accesos rápidos a los distintos cursos del sitio.

### 🎓 Programas / Servicios

Sección donde se detallan las distintas propuestas formativas:

* Preparación para ingreso universitario
* Preparación para nivel secundario (medio y técnico)
* Apoyatura académica terciaria y universitaria

Cada programa incluye una descripción general de los contenidos, objetivos y enfoque pedagógico.

### 📚 Metodología

Explicación del enfoque de enseñanza:

* Aprendizaje progresivo
* Resolución de problemas
* Enfoque práctico
* Adaptación al ritmo del estudiante

### 👨‍🏫 Sobre nosotros

Información institucional y presentación del docente/proyecto.

### 📞 Contacto

Sección destinada a la comunicación con potenciales estudiantes.

Puede incluir:

* Formulario de contacto
* Email
* Acceso directo a WhatsApp
